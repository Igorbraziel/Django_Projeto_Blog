# Projeto Blog com Django e Docker

Este projeto é uma aplicação web de Blog desenvolvida com o framework **Django** e containerizada com **Docker**, com o objetivo de gerenciar postagens de forma simples e eficiente. A aplicação permite criar, visualizar, editar e excluir posts, além de contar com um painel administrativo para gerenciamento completo do conteúdo.

---

## Funcionalidades

- ✅ Criação de postagens com título, conteúdo e data.
- ✅ Listagem pública dos posts.
- ✅ Edição e exclusão de postagens.
- ✅ Painel administrativo com autenticação via Django Admin.
- ✅ Templates HTML reutilizáveis com estilização moderna.
- ✅ Ambiente totalmente containerizado com Docker.

---

## Tecnologias utilizadas

- Python 3
- Django
- PostgreSQL
- HTML5, CSS3
- Docker e Docker Compose
- Git e GitHub
